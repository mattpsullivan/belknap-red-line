# Reference source material

## `belknap-range-trails-map-bosworth-2018.jpg`

The authoritative **Belknap Range Trails** map by Weldon Bosworth (2/8/2018),
the source the `PointOfInterest` type cites for POI grid cells and historical
features. Photographed from the trailhead banner and cropped to the printed map
face (title, legend, grid A-J x 1-12, and the topo).

Trails on the original were GPS'd by R. Andrews, S. Zimmer & W. Bosworth.

Use it to verify the trail **graph** (connectivity, which trails meet where),
POI placement against the grid, and to eyeball whether the shapes of trails we
have GPS tracks for match the map. It is **not** a source of coordinates: the
sheet has a lettered/numbered grid but no lat/lng graticule, so nothing precise
can be derived from this photo. Real coordinates come from the credited GPX or
field tracks.
