# Product Overview - Belknap Red-Line Tracker

## Vision

A mobile-first Progressive Web App that empowers hikers to track their progress "red-lining" the Belknap Range trail system in New Hampshire.

**"Red-lining"** is the hiking practice of hiking every trail in a given area, traditionally marked with a red line on a paper map. This app brings that concept into the digital age.

## The Problem

Hikers who want to complete all trails in the Belknap Range face several challenges:

1. **Tracking progress is tedious** - Paper checklists get lost or damaged
2. **Trail information is scattered** - Multiple sources, inconsistent data
3. **No connectivity in backcountry** - Online maps fail when you need them most
4. **Difficult to plan multi-trail hikes** - Understanding trail connections requires experience
5. **No visual progress feedback** - Hard to see how much you've accomplished

## The Solution

Belknap Red-Line Tracker provides:

- **Visual progress tracking** with interactive map and statistics
- **Offline-first design** that works without cell service
- **GPS track recording** with automatic trail detection
- **Pre-built loop itineraries** for planning multi-trail hikes
- **Comprehensive trail data** with elevation profiles and difficulty ratings

## Target Users

### Primary: The Completionist Hiker

- Goal: Hike every trail in the Belknap Range
- Tracks progress over months or years
- Values reliability over features
- Uses the app before, during, and after hikes

### Secondary: The Casual Day Hiker

- Goal: Explore new trails in the area
- Visits occasionally, may not complete all trails
- Values discovery and planning features
- Uses the app primarily before hikes

## Key Features

### 1. Progress Dashboard

The home screen shows at-a-glance progress:

- Overall completion percentage
- Trails completed vs. total (59 trails, 67.7 miles)
- Total distance hiked
- Recent completions timeline

### 2. Interactive Trail Map

Full-screen map with:

- All trails color-coded by completion status
  - **Red** = Completed ("red-lined")
  - **Blue** = Not yet hiked
- Tap any trail for quick info popup
- Link to trail details from popup
- Current location tracking
- Offline tile support

### 3. Trail Directory

Searchable, filterable list of all 59 trails:

- Filter by area (8 regions)
- Filter by difficulty (Easy/Moderate/Difficult)
- Sort by name, distance, or elevation
- Quick mark-complete action

### 4. Trail Details

Comprehensive view of each trail:

- Distance, difficulty, elevation gain/loss
- Interactive elevation profile
- "View on Map" with zoom and highlight
- Mark complete with optional notes
- Part of which loops

### 5. GPS Track Recording

Record your hike with device GPS:

- Real-time position on map
- Automatic trail detection
- Coverage percentage tracking
- Prompt to mark trails complete after hike
- Track history with playback

### 6. Loop Itineraries

Pre-built multi-trail hikes:

- Curated loop routes
- Combined elevation profile
- Difficulty rating and time estimate
- View all loop trails on map
- Track completion of loop components

### 7. Offline Support

Full functionality without internet:

- Cached map tiles
- All trail data bundled
- GPS recording works offline
- Data syncs when online

## Technical Highlights

### Privacy First

- **No user accounts** - No login required
- **All data local** - Stored only on user's device
- **No analytics** - No tracking or telemetry
- **No server** - Works entirely client-side

### Progressive Web App

- **Installable** - Add to home screen on iOS/Android
- **Offline capable** - Full functionality without network
- **App-like experience** - Native feel with web technology

### Data Portability

- **Export** - Download completions as CSV
- **Import** - Restore from CSV backup
- **BRATTS compatible** - Export format matches original workbook
